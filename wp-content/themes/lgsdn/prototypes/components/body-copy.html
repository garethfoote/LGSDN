Designing services people can use

Readable, semantic body copy helps people understand an article and move through it using the tools that work for them.

Published 22 July 2026 by the LGSDN team

The Local Government Service Design Network shares practical work from councils. You can read an example of a clear section, follow links without relying on colour alone, and zoom the page without losing content.

Use strong importance only when the meaning calls for it, and emphasis when the stress changes how a sentence is understood. The LGSDN abbreviation is expanded in the markup.

A clear section heading

Headings describe the content that follows and form a logical outline. They should not be chosen for their visual size. Short paragraphs and meaningful link text make scanning easier.

Lists

Use an unordered list when sequence does not matter:

  • write in plain language
  • put the most important information first
  • test with people who use assistive technology

Use an ordered list when the order is meaningful:

  1. understand the user need
  2. publish the smallest useful answer
  3. measure and improve it

Quotation

Accessibility is part of the service, not a final check at the end.

LGSDN accessibility principle

Terms and supporting text

Plain language
Writing that helps the intended audience understand the message the first time they read it.
Semantic HTML
Elements chosen for their meaning so browsers and assistive technologies can expose the correct structure.

Inline code such as aria-label, keyboard input such as Tab, and highlighted text remain legible against their backgrounds.

<main id="main-content">
  <h1>A descriptive page title</h1>
</main>
